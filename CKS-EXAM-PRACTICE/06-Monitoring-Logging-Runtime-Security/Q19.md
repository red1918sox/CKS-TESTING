# Q19 — Monitoring, Logging & Runtime Security

Using Falco, write a custom rule that alerts whenever a shell is spawned inside a container in namespace `production`.

<details><summary>Solution</summary>

```yaml
- rule: Shell Spawned in Production
  desc: Detect shell spawned in production namespace
  condition: >
    spawned_process and container and
    k8s.ns.name = "production" and
    proc.name in (bash, sh, zsh)
  output: >
    Shell spawned in production (user=%user.name container=%container.name
    command=%proc.cmdline)
  priority: WARNING
```
</details>
