# Q18 — Monitoring, Logging & Runtime Security

Enable audit logging on the apiserver: log all `delete` requests at `RequestResponse` level, everything else at `Metadata` level, writing to `/var/log/kubernetes/audit.log` with 7-day retention.

<details><summary>Solution</summary>

```yaml
# /etc/kubernetes/audit-policy.yaml
apiVersion: audit.k8s.io/v1
kind: Policy
rules:
- level: RequestResponse
  verbs: ["delete"]
- level: Metadata
```
```bash
# kube-apiserver.yaml flags:
--audit-policy-file=/etc/kubernetes/audit-policy.yaml
--audit-log-path=/var/log/kubernetes/audit.log
--audit-log-maxage=7
```
</details>
