# Q20 — Monitoring, Logging & Runtime Security

A pod was compromised and is making suspicious outbound connections. Immediately isolate it at the network layer without deleting the pod (preserve forensic state), then capture a snapshot of running processes inside it.

<details><summary>Solution</summary>

```bash
# Isolate: apply a deny-all NetworkPolicy targeting just this pod's labels
kubectl label pod <pod> forensics=isolate
cat <<EOF | kubectl apply -f -
apiVersion: networking.k8s.io/v1
kind: NetworkPolicy
metadata:
  name: isolate-compromised
  namespace: <ns>
spec:
  podSelector:
    matchLabels:
      forensics: isolate
  policyTypes: ["Ingress", "Egress"]
EOF

# Capture process snapshot
kubectl exec <pod> -- ps aux > forensics-ps-snapshot.txt
```
</details>
