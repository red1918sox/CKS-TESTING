# Q21 — Cluster Setup

Worker node `node02` is one patch version behind the control plane (e.g. control plane is on `v1.31.4`, node02 is on `v1.31.3`). Safely drain it, upgrade `kubeadm`, `kubelet`, and `kubectl` to match, then return it to service.

<details><summary>Solution</summary>

```bash
# From the control plane
kubectl drain node02 --ignore-daemonsets --delete-emptydir-data --force

ssh node02
sudo -i

apt update
apt-cache madison kubeadm | grep 1.31
apt-mark unhold kubeadm
apt-get install -y kubeadm=1.31.4-1.1
apt-mark hold kubeadm

kubeadm upgrade node

apt-mark unhold kubelet kubectl
apt-get install -y kubelet=1.31.4-1.1 kubectl=1.31.4-1.1
apt-mark hold kubelet kubectl

systemctl daemon-reload
systemctl restart kubelet
exit

# Back on the control plane
kubectl uncordon node02
kubectl get nodes
```
</details>
