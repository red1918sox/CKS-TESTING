# Q1 — Cluster Setup

A CIS benchmark scan flagged that the kube-apiserver is running with `--insecure-port=8080`. Fix the static pod manifest on the control plane node to disable the insecure port, then verify the apiserver restarts healthy.

<details><summary>Solution</summary>

```bash
# Edit the manifest (kubelet watches this path and restarts automatically)
vi /etc/kubernetes/manifests/kube-apiserver.yaml
# Remove --insecure-port=8080 (or set to 0 on older versions)
# Save and wait ~30s
watch crictl ps   # confirm apiserver container restarts
kubectl get --raw='/healthz'
```
</details>
