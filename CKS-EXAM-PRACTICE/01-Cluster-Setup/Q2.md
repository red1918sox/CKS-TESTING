# Q2 — Cluster Setup

Using `kubeadm`, a new worker node `worker3` needs to join the cluster. Generate a fresh join command with a short-lived token (TTL 10m) on the control plane, and join the node.

<details><summary>Solution</summary>

```bash
# On control plane
kubeadm token create --ttl 10m --print-join-command

# On worker3, run the printed command, e.g.:
kubeadm join 10.0.0.1:6443 --token abcdef.0123456789abcdef \
  --discovery-token-ca-cert-hash sha256:<hash>
```
</details>
