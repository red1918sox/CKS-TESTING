# Q15 — Supply Chain Security

Configure an `ImagePolicyWebhook` admission controller so only images from `registry.company.com/` are allowed cluster-wide; all others must be rejected.

<details><summary>Solution</summary>

```yaml
# /etc/kubernetes/admission/admission-config.yaml
apiVersion: apiserver.config.k8s.io/v1
kind: AdmissionConfiguration
plugins:
- name: ImagePolicyWebhook
  configuration:
    imagePolicy:
      kubeConfigFile: /etc/kubernetes/admission/webhook-kubeconfig.yaml
      allowTTL: 50
      denyTTL: 50
      retryBackoff: 500
      defaultAllow: false

# kube-apiserver flags:
# --enable-admission-plugins=...,ImagePolicyWebhook
# --admission-control-config-file=/etc/kubernetes/admission/admission-config.yaml
```
Webhook backend logic rejects any image not matching `registry.company.com/*`.
</details>
