# Q26 — Supply Chain Security

Generate an SPDX SBOM for the image `myregistry.io/service-x:2.1` using the `bom` tool, then use it to check whether the image bundles `openssl` below the version your org considers safe.

<details><summary>Solution</summary>

```bash
bom generate --image myregistry.io/service-x:2.1 --output service-x.spdx

# Inspect for the package of interest
grep -A3 -i "openssl" service-x.spdx
```

If an unsafe version is found, rebuild from an updated base image and remove the vulnerable container/image reference from the Deployment until it's patched.
</details>
