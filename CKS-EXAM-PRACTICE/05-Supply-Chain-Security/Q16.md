# Q16 — Supply Chain Security

Use `kubesec` or `docker scout`/`trivy config` to statically analyze a Dockerfile that runs as root and uses `ADD` from a URL. Identify and fix the two issues.

<details><summary>Solution</summary>

Issues: running as root, `ADD <url>` (supply-chain risk, no integrity check — prefer `COPY` + checksum verification).

```dockerfile
FROM alpine:3.19
RUN addgroup -S app && adduser -S app -G app
COPY --chown=app:app ./app /app
USER app
ENTRYPOINT ["/app/start.sh"]
```
</details>
