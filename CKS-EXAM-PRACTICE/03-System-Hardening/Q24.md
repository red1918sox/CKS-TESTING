# Q24 — System Hardening

On a build host, user `ci-runner` was mistakenly added to the `docker` group — which is effectively root-equivalent access, since anyone in that group can talk to the Docker daemon socket. Remove `ci-runner` from the `docker` group, then confirm the socket itself has safe ownership/permissions.

<details><summary>Solution</summary>

```bash
# Remove the user from the docker group
gpasswd -d ci-runner docker

# Confirm socket ownership/permissions
ls -l /var/run/docker.sock
# Expected: srw-rw---- 1 root docker ... /var/run/docker.sock
chown root:docker /var/run/docker.sock
chmod 660 /var/run/docker.sock

# Verify ci-runner no longer has access
su - ci-runner -c "docker ps"   # should fail with permission denied
```
</details>
