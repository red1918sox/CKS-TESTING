# Q8 — System Hardening

Write a Seccomp profile named `audit.json` that logs (but doesn't block) all syscalls, place it correctly for the kubelet, and apply it to a pod `seccomp-demo`.

<details><summary>Solution</summary>

```bash
mkdir -p /var/lib/kubelet/seccomp/profiles
cat <<EOF > /var/lib/kubelet/seccomp/profiles/audit.json
{"defaultAction": "SCMP_ACT_LOG"}
EOF
```
```yaml
apiVersion: v1
kind: Pod
metadata:
  name: seccomp-demo
spec:
  securityContext:
    seccompProfile:
      type: Localhost
      localhostProfile: profiles/audit.json
  containers:
  - name: demo
    image: busybox
    command: ["sleep", "3600"]
```
</details>
