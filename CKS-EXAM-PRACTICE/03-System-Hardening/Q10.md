# Q10 — System Hardening

Use `AppArmor` to restrict a container to a profile named `k8s-restricted` that is already loaded on the node. Apply it via annotation (pre-1.30 style) and confirm enforcement.

<details><summary>Solution</summary>

```yaml
metadata:
  annotations:
    container.apparmor.security.beta.kubernetes.io/app: localhost/k8s-restricted
spec:
  containers:
  - name: app
    image: myapp:1.0
```
```bash
kubectl exec <pod> -- cat /proc/1/attr/current
```
</details>
