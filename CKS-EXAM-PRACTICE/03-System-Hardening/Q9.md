# Q9 — System Hardening

Harden a pod spec so it runs as a non-root UID 1000, drops all Linux capabilities, and has a read-only root filesystem.

<details><summary>Solution</summary>

```yaml
spec:
  securityContext:
    runAsNonRoot: true
    runAsUser: 1000
  containers:
  - name: app
    image: myapp:1.0
    securityContext:
      readOnlyRootFilesystem: true
      allowPrivilegeEscalation: false
      capabilities:
        drop: ["ALL"]
```
</details>
