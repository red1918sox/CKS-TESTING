# Q7 — Cluster Hardening

A secret `db-creds` was created with `kubectl create secret generic`. Verify whether etcd encryption-at-rest is enabled; if not, configure an `EncryptionConfiguration` using `aescbc` and re-encrypt existing secrets.

<details><summary>Solution</summary>

```bash
# Check apiserver flags
grep encryption-provider-config /etc/kubernetes/manifests/kube-apiserver.yaml

# Create /etc/kubernetes/enc/enc.yaml
apiVersion: apiserver.config.k8s.io/v1
kind: EncryptionConfiguration
resources:
  - resources: ["secrets"]
    providers:
      - aescbc:
          keys:
            - name: key1
              secret: <base64 32-byte key>
      - identity: {}

# Add to kube-apiserver.yaml:
# --encryption-provider-config=/etc/kubernetes/enc/enc.yaml
# mount the /etc/kubernetes/enc volume

# Re-encrypt existing secrets
kubectl get secrets -A -o json | kubectl replace -f -
```
</details>
