# Q5 — Cluster Hardening

Disable anonymous authentication on the kubelet for all nodes, and ensure the kubelet only allows authorized API calls via webhook authorization.

<details><summary>Solution</summary>

```bash
# On each node, edit kubelet config (commonly /var/lib/kubelet/config.yaml)
authentication:
  anonymous:
    enabled: false
authorization:
  mode: Webhook

systemctl restart kubelet
```
</details>
