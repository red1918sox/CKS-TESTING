# Q23 — Cluster Hardening

Harden kube-apiserver authorization so that kubelets can only read/modify objects related to the node they run on (preventing a compromised kubelet from tampering with unrelated resources). Enable `Node,RBAC` authorization mode and the `NodeRestriction` admission plugin, and disable anonymous authentication.

<details><summary>Solution</summary>

```bash
vi /etc/kubernetes/manifests/kube-apiserver.yaml
```
```yaml
spec:
  containers:
  - command:
    - kube-apiserver
    - --anonymous-auth=false
    - --authorization-mode=Node,RBAC
    - --enable-admission-plugins=NodeRestriction,...   # append to existing list, don't replace it
```
```bash
# kubelet watches the manifest path, apiserver restarts automatically
watch crictl ps
kubectl get --raw='/healthz'
```
</details>
