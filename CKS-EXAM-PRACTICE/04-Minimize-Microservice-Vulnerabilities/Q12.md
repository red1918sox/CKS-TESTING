# Q12 — Minimize Microservice Vulnerabilities

A deployment mounts a `Secret` as an environment variable. Refactor it to mount the secret as a volume instead (more secure against process-list/env leakage), at path `/etc/secret-vol`, read-only.

<details><summary>Solution</summary>

```yaml
spec:
  containers:
  - name: app
    image: myapp:1.0
    volumeMounts:
    - name: secret-vol
      mountPath: /etc/secret-vol
      readOnly: true
  volumes:
  - name: secret-vol
    secret:
      secretName: db-creds
```
</details>
