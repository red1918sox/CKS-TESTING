# Q13 — Minimize Microservice Vulnerabilities

Write an OPA Gatekeeper `ConstraintTemplate` + `Constraint` that rejects any Pod without `resources.limits.memory` defined.

<details><summary>Solution</summary>

```yaml
apiVersion: templates.gatekeeper.sh/v1
kind: ConstraintTemplate
metadata:
  name: requirememorylimit
spec:
  crd:
    spec:
      names:
        kind: RequireMemoryLimit
  targets:
  - target: admission.k8s.gatekeeper.sh
    rego: |
      package requirememorylimit
      violation[{"msg": msg}] {
        container := input.review.object.spec.containers[_]
        not container.resources.limits.memory
        msg := sprintf("container %v has no memory limit", [container.name])
      }
---
apiVersion: constraints.gatekeeper.sh/v1beta1
kind: RequireMemoryLimit
metadata:
  name: require-memory-limit
spec:
  match:
    kinds:
    - apiGroups: [""]
      kinds: ["Pod"]
```
</details>
