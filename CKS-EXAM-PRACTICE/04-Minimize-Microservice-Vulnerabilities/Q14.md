# Q14 — Minimize Microservice Vulnerabilities

Scan the image `myregistry.io/app:1.4` for critical CVEs using Trivy, and fail the pipeline (exit nonzero) only on CRITICAL severity.

<details><summary>Solution</summary>

```bash
trivy image --severity CRITICAL --exit-code 1 myregistry.io/app:1.4
```
</details>
