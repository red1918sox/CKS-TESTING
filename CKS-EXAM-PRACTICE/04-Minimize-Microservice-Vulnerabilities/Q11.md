# Q11 — Minimize Microservice Vulnerabilities

Enforce Pod Security Standards at the `restricted` level on namespace `secure-apps` using labels (built-in admission controller, no third-party tool).

<details><summary>Solution</summary>

```bash
kubectl label ns secure-apps \
  pod-security.kubernetes.io/enforce=restricted \
  pod-security.kubernetes.io/warn=restricted
```
</details>
